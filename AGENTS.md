# Sobrou 2.0 App

## Stack

- React Native + Expo SDK 54
- JavaScript
- Supabase (backend/auth)

## Quem sou eu

Sou o Leo, desenvolvedor iniciante. Sigo instruções, colo prompts e interpreto erros,
mas não escrevo código do zero. Fale comigo em português, simples e passo a passo,
dizendo sempre o que clicar e onde colar. Nunca jogue código solto.

## Regras para código

- Sempre usar componentes React Native: View, Text, Pressable, ScrollView
- NUNCA usar div, className, Tailwind ou CSS web
- Animações com React Native Animated API
- Estilo sempre via StyleSheet.create()

## Skills instaladas

- design-taste-frontend: princípios de design premium adaptados para RN
- impeccable: usar /audit e /polish para revisar componentes
- emil-design-eng: animações < 300ms, easing customizado, sem ease-in
- diagnostico-de-erros: ao aparecer qualquer erro, traduzir em português, achar a causa
  e dar o conserto passo a passo. Também roda a verificação de fim de sessão.
- github-seguro: guia para salvar/subir código com segurança e desfazer sem perder trabalho.

## Verificação de fim de sessão (OBRIGATÓRIA)

Sempre que eu sinalizar que vou parar/encerrar, ou antes de commitar/subir pro GitHub,
rode automaticamente a verificação de fim de sessão da skill `diagnostico-de-erros`,
sem eu precisar pedir. Confira: (1) se o código está quebrando, (2) se está consistente,
(3) se há erros canônicos/comuns, (4) se realmente faz o que eu queria.
Relate com status ✅ / ⚠️ / ❌ e só me libere pra subir pro GitHub quando não houver ❌.

## Antes de mexer em algo arriscado

- Antes de mudanças grandes ou que apagam/sobrescrevem coisas, avise e confirme comigo.
- Sugira salvar um "checkpoint" no Git antes, pra poder voltar se quebrar.
